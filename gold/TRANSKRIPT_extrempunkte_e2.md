# Transkript des Films „Extrempunkte" (so, wie ein Leser ihn auf dem Handy erlebt)

Der Film ist eine Folge von Blättern. Jedes Blatt ist ein Bildschirm. Man wischt nach unten; mit jedem Wisch kommen Blöcke dazu (von oben nach unten) und bleiben stehen, bis das Blatt voll ist. Dann blendet das nächste Blatt über. Was in eckigen Klammern steht, ist das, was man sieht, ohne Worte. Farben: alles, was zu x₁ gehört, ist orange; alles zu x₂ blau; zu x₃ grün.

## Blatt 1 (oben klein: „Woran erkennt man einen Gipfel?")
Überschrift: Extrempunkte (Hoch- und Tiefpunkte)
Ein Hochpunkt ist ein Gipfel des Graphen, ein Tiefpunkt ist ein Tal.
[Graph zeichnet sich: f(x) = x³ − 3x, x von −2,4 bis 2,4, y von −4 bis 4. Ein oranger Punkt landet auf dem Gipfel, Beschriftung H(−1|2). Ein blauer Punkt landet im Tal, Beschriftung T(1|−2).]
Fahrt mit der Tangente über den Graphen. Die Zahl m ist ihre Steigung.
[Beim Wischen fährt eine orange Berührgerade mit Punkt von links nach rechts über die Kurve. Oben links im Bild steht laufend „x = …" und „m = …", die Zahlen ändern sich mit dem Wischen (etwa x = −2,0 m = 9,0; x = −1,0 m = 0,0; x = 0 m = −3,0; x = 1,0 m = 0,0; x = 2,0 m = 9,0). Wenn die Fahrt an −1 vorbeikommt, bleibt dort eine waagerechte orange Gerade durch H liegen, daneben „m = 0". Ebenso bei 1 durch T. Am Ende verschwindet die fahrende Tangente, die zwei waagerechten bleiben.]
An beiden ist die Tangente waagerecht.
[gelb hinterlegt:] m = f'(x) = 0

## Blatt 2 („Wo liegen Gipfel und Tal?")
Gesucht sind die Stellen, an denen die Tangente waagerecht ist.
NOTWENDIGE BEDINGUNG: f'(x) = 0
[Graph zeichnet sich neu: f(x) = x³ − 3x, ohne Punkte.]
f(x) = x³ − 3x
f'(x) = 3x² − 3
[Stück für Stück in Leserichtung:] 3x² − 3 = 0 ⟺ x² = 1 ⟺ x₁ = −1 (orange), x₂ = 1 (blau)
Zwei Stellen. Ob Gipfel oder Tal, sagt das noch nicht.
[Die orange „−1" löst sich als Kopie aus der Zeile und fliegt hinauf zur x-Achse des Graphen; dort erscheint bei −1 ein oranges Dreieck an der Achse mit der Zahl −1 darunter. Dann dasselbe blau für die 1.]

## Blatt 3 („Welche Stelle ist der Gipfel, und wie hoch liegt er?")
[Graph f(x) = x³ − 3x, kleiner, mit den zwei Achsenmarken −1 (orange) und 1 (blau), ohne Punkte.]
x₁ = −1 (orange)    x₂ = 1 (blau)
HINREICHENDE BEDINGUNG: f''(x) ≠ 0
f''(x) = 6x
[Ein oranger Pfeil zieht sich langsam: er startet unter der „−1" der Zeile x₁ = −1, geht nach unten in den Zwischenraum, nach links in den Rand neben dem Text, senkrecht hinunter und dann waagerecht mit Spitze auf den Anfang der nächsten Zeile.]
f''(−1) = 6·(−1) = −6  < 0  → Hochpunkt   [orange, Chip für Chip]
[Im Graphen leuchtet das Kurvenstück um x = −1 dick orange auf, geformt wie ∩, darüber klein „Rechtskurve".]
[Ein blauer Pfeil ebenso von der „1" der Zeile x₂ = 1, im Rand etwas weiter außen, zur folgenden Zeile.]
f''(1) = 6·1 = 6  > 0  → Tiefpunkt   [blau]
[Kurvenstück um x = 1 leuchtet blau auf, geformt wie ∪, darunter „Linkskurve".]
Y-WERTE: y = f(x)
[Der orange Pfeil verzweigt: vom Rand aus ein weiterer Ast senkrecht hinunter, dann waagerecht auf die Zeile:]
f(−1) = (−1)³ − 3·(−1) = −1 + 3 = 2   [orange]
[Im Graphen läuft von der Achsenmarke −1 eine gestrichelte orange Linie senkrecht hinauf bis zur Kurve und dann waagerecht zur y-Achse, dort steht „2"; ein oranger Punkt landet auf der Kurve.]
[Blauer Ast ebenso zur nächsten Zeile:]
f(1) = 1³ − 3·1 = 1 − 3 = −2   [blau]
[Gestrichelte blaue Linie von der Marke 1 hinunter zur Kurve und zur y-Achse „−2"; blauer Punkt landet.]
[Eine Ergebniszeile erscheint, zunächst nur mit den Klammern „( | )": Dann fliegen Kopien heran und setzen sich ein: das „H" aus „Hochpunkt" fliegt vor die Klammer, die orange „−1" aus der Zeile x₁ = −1 fliegt in die Klammer, die orange „2" vom Ende der Zeile f(−1) = … fliegt hinter den Strich. Danach dasselbe blau: „T", „1", „−2".]
H(−1|2),  T(1|−2)
[Im Graphen erscheinen die Beschriftungen H(−1|2) am orangen Punkt und T(1|−2) am blauen.]
Merksatz (fett, mit Balken): Der y-Wert kommt aus f(x), nicht aus f'(x).

## Blatt 4 („Geht das bei g genauso?")
g(x) = x² − 4x
[Graph zeichnet sich: g(x) = x² − 4x, x von −1,2 bis 5,2, y von −5 bis 3.]
NOTWENDIGE BEDINGUNG: g'(x) = 0
g'(x) = 2x − 4
2x − 4 = 0 ⟺ x₁ = 2 (orange)
[Die „2" fliegt zur x-Achse; orange Marke bei 2.]
HINREICHENDE BEDINGUNG: g''(x) ≠ 0
g''(x) = 2
[Oranger Randpfeil von der „2" zur nächsten Zeile.]
g''(2) = 2  > 0  → Tiefpunkt
[Kurvenstück um x = 2 leuchtet orange, ∪-förmig, ohne Beschriftung.]
Y-WERTE: y = g(x)
[Pfeilast zur Zeile:]
g(2) = 2² − 4·2 = −4
[Gestrichelter Aufstieg von der Marke 2 hinunter zur Kurve und zur y-Achse „−4"; Punkt landet.]
[Ergebniszeile setzt sich aus fliegenden Kopien zusammen: „T", „2", „−4".]
T(2|−4)
[Beschriftung T(2|−4) am Punkt.]

## Blatt 5 („Und mit zwei Kandidaten?")
h(x) = −x³ + 3x
[Graph: h(x) = −x³ + 3x, x von −2,4 bis 2,4, y von −4 bis 4.]
NOTWENDIGE BEDINGUNG: h'(x) = 0
h'(x) = −3x² + 3
−3x² + 3 = 0 ⟺ x² = 1 ⟺ x₁ = −1 (orange), x₂ = 1 (blau)
[Beide Zahlen fliegen zur Achse; Marken bei −1 orange, 1 blau.]
HINREICHENDE BEDINGUNG: h''(x) ≠ 0
h''(x) = −6x
[oranger Pfeil] h''(−1) = 6  > 0  → Tiefpunkt   [Kurvenstück bei −1 orange, ∪]
[blauer Pfeil] h''(1) = −6  < 0  → Hochpunkt   [Kurvenstück bei 1 blau, ∩]
Y-WERTE: y = h(x)
[Äste] h(−1) = −(−1)³ + 3·(−1) = 1 − 3 = −2   [Aufstieg zur Kurve, „−2" an der y-Achse, oranger Punkt]
h(1) = −1³ + 3·1 = −1 + 3 = 2   [Aufstieg, „2", blauer Punkt]
[Ergebniszeile fliegt zusammen:] T(−1|−2),  H(1|2)
[Beschriftungen an den Punkten.]

## Blatt 6 („Und mit drei?")
k(x) = x⁴ − 2x²
[Graph: k(x) = x⁴ − 2x², x von −1,9 bis 1,9, y von −1,6 bis 2,4. Die Kurve verlässt oben links und rechts das Bild.]
NOTWENDIGE BEDINGUNG: k'(x) = 0
k'(x) = 4x³ − 4x = 4x(x² − 1)
4x(x² − 1) = 0 ⟺ x₁ = 0 (orange), x₂ = −1 (blau), x₃ = 1 (grün)
[Drei Zahlen fliegen zur Achse; Marken 0 orange, −1 blau, 1 grün.]
HINREICHENDE BEDINGUNG: k''(x) ≠ 0
k''(x) = 12x² − 4
[oranger Pfeil] k''(0) = −4  < 0  → Hochpunkt   [Kurvenstück bei 0 orange, ∩]
[blauer und grüner Pfeil auf dieselbe Zeile] k''(±1) = 8  > 0  → Tiefpunkte   [Kurvenstücke bei −1 blau und 1 grün, beide ∪]
Y-WERTE: y = k(x)
[drei Pfeiläste, jeder mit Spitze von oben auf seinen Teil der Zeile:]
k(0) = 0,  k(−1) = 1 − 2 = −1,  k(1) = 1 − 2 = −1
[Punkte landen: orange bei (0|0), blau bei (−1|−1) mit Aufstieg und „−1" an der y-Achse, grün bei (1|−1).]
[Ergebniszeile fliegt zusammen, neun Kopien:] H(0|0),  T₁(−1|−1),  T₂(1|−1)
[Beschriftungen an den Punkten.]

## Blatt 7 („Und wenn eˣ drinsteckt?")
m(x) = x·eˣ
[Graph: m(x) = x·eˣ, x von −4,6 bis 1,1, y von −0,8 bis 1,6. Kurve kommt von links nahe der Achse, taucht bis etwa −0,37 ab und steigt rechts steil aus dem Bild.]
NOTWENDIGE BEDINGUNG: m'(x) = 0
m'(x) = 1·eˣ + x·eˣ = (1 + x)·eˣ
(1 + x)·eˣ = 0 ⟺ 1 + x = 0 ⟺ x₁ = −1 (orange)   | eˣ ≠ 0
[„−1" fliegt zur Achse, Marke bei −1.]
HINREICHENDE BEDINGUNG: m''(x) ≠ 0
m''(x) = (2 + x)·eˣ
[oranger Pfeil] m''(−1) = 1·e⁻¹ ≈ 0,37  > 0  → Tiefpunkt   [Kurvenstück bei −1 orange, ∪]
Y-WERTE: y = m(x)
[Ast] m(−1) = −1·e⁻¹ ≈ −0,37   [Aufstieg, „−0,37" an der y-Achse, Punkt landet]
[Ergebniszeile fliegt zusammen:] T(−1|−0,37)

## Blatt 8 („Was bleibt als Weg?")
Überschrift: Schema
NOTWENDIGE BEDINGUNG
[gelb:] f'(x₀) = 0
HINREICHENDE BEDINGUNG
f''(x₀) < 0   ∩   →  H(x₀ | f(x₀))     [orange]
f''(x₀) > 0   ∪   →  T(x₀ | f(x₀))     [blau]
f''(x₀) = 0   →  keine Entscheidung, Vorzeichen von f′ links und rechts prüfen
Merksatz: f'(x) = 0 liefert die Kandidaten: dort ist die Tangente waagerecht. f'' entscheidet: negativ heißt Rechtskurve, also Gipfel. Positiv heißt Linkskurve, also Tal.
